隐私政策

生效日期：2026 年 10 月 20 日

番忆（AnimeMemo，以下简称“本应用”）是一款本地优先的 iOS 追番记录工具。 本政策说明本应用如何处理你的信息。核心原则很简单： 本应用没有账号系统，不收集你的个人信息，不包含广告或第三方分析 SDK。

1. 我们收集什么

本应用不收集、不上传、不出售你的个人信息。具体来说：

  • 不需要注册账号，不收集姓名、邮箱、手机号或位置。
  • 不包含第三方广告、分析或追踪 SDK。
  • 没有开发者运营的服务器，不会把你的片库上传到云端。

2. 保存在本机的数据

以下数据仅保存在你的设备上：

  • 你加入片库的作品、观看进度、评分、笔记和收藏状态。
  • 标题语言、外观等设置。
  • 你主动导出的 JSON 备份文件（由你选择保存位置）。

删除本应用会删除应用内的本地数据。你也可以在设置中使用“清空全部数据”。 如果你希望保留记录，请先使用“导出备份”。

3. TMDB 元数据请求

本应用使用 TMDB API 获取作品名称、简介、海报、播出信息等元数据。 当你搜索或打开作品详情时，应用会向 TMDB 发送搜索关键词、作品 ID 和常规网络请求信息 （例如 IP 地址、设备网络环境）。这些请求直接发往 TMDB，不经过开发者服务器。

TMDB 对这些请求的处理受其自身隐私政策约束： https://www.themoviedb.org/privacy-policy。 本应用不会把 TMDB 返回的数据用于广告画像或出售。

4. 图片与缓存

海报和剧照由 TMDB 图片 CDN 提供，并可能在本机缓存以提升加载速度。 缓存仅用于展示，不会上传到开发者服务器。你可以在设置中清除图片缓存。

5. 备份与导出

JSON 备份由你主动触发。导出后文件保存到你选择的位置（例如“文件”App、iCloud Drive 或其他第三方位置），其后续处理取决于你选择的存储服务，而不受本应用控制。

6. 儿童隐私

本应用不是面向儿童设计的产品，也不会有意收集儿童的个人信息。 由于本应用不收集账号或个人资料，这一风险在本应用的设计中被降到最低。

7. 第三方服务

当前版本涉及的外部服务只有：

  • TMDB：影视元数据和图片。详见其隐私政策。
  • Apple：App Store 分发、系统能力和设备备份。详见 Apple 的隐私政策。

8. 政策更新

如果未来版本增加账号、云同步、通知或分析功能，本政策会相应更新， 并在本页面注明新的生效日期。重大变化会在应用内或版本说明中提示。

9. 联系我们

如对本政策有疑问，可以通过 GitHub 仓库提交 Issue： https://github.com/shiyuwudi1/anime-memo-ios/issues 。

10. TMDB 声明

This product uses the TMDB API but is not endorsed or certified by TMDB. 本应用是非官方第三方应用，与 TMDB 没有隶属或背书关系。
