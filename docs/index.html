追番这件小事，
应该更简单。

没有社交压力，没有签到打卡，也没有“猜你喜欢”。只记录你真正看过的每一话。

中

中文搜番

搜中文名、日文名或英文名。找不到时，可以试试原名。

＋

一键 +1

首页、片库、详情页都能记一话。进度到了总话数，自动提示看完。

季

按季记录

每一季有自己的进度、评分和笔记，不会把第 1 季和第 2 季混在一起。

日

今日更新

打开首页就知道今天哪部在追的番更新了，不用自己记播出日。

⌂

数据只在本机

没有账号，没有云同步，没有开发者服务器。你的片库和笔记只存在设备上。

◐

Liquid Glass

为 iOS 26/27 的原生液态玻璃设计，内容和控件保持清晰分层。

不登录，也能好好记

V1 不需要注册。打开 App 就能搜索、加入片库、记录进度。换机或重装前，可以在设置里导出 JSON 备份。

数据来源

本应用使用 TMDB API 获取影视元数据和图片，但未获得 TMDB 的认可或认证。详见 隐私政策。
